## My favourite math formulas

Ось деякі з моїх улюблених математичних формул:

![Formula 1](https://latex.codecogs.com/svg.latex?\lim_{\Delta%20x%20\to%200}f(x_{0}%20+%20\Delta%20x)%20=%20f(x_{0}))  
*Це визначення неперервності функції через границю в точці $x_{0}$, де використовується приріст $\Delta x$.*

![Formula 2](https://latex.codecogs.com/svg.latex?\sin^{2}\alpha%20+%20\cos^{2}\beta%20=%201)  
*Це основна тригонометрична тотожність для кутів $\alpha$ та $\beta$.*

![Formula 3](https://latex.codecogs.com/svg.latex?\log_{a}(x^{y})%20=%20y%20\cdot%20\log_{a}(x),\quad%20\text{де}\%20a%20>%200,%20a%20\neq%201)  
*Це властивість логарифмів із показником степеня $y$ та основою $a$.*

![Formula 4](https://latex.codecogs.com/svg.latex?\begin{cases}\sin%20x%20+%20\cos%20y%20=%201\\\sin%20x%20-%20\cos%20y%20=%200\\\operatorname{tg}%20x%20\cdot%20\operatorname{ctg}%20y%20=%201\end{cases})  
*Це тригонометрична система рівнянь відносно кутів $x$ та $y$.*

![Formula 5](https://latex.codecogs.com/svg.latex?\sum_{k=1}^{n}k^{2}%20=%20\frac{n(n%20+%201)(2n%20+%201)}{6})  
*Це формула для обчислення суми квадратів перших $n$ натуральних чисел.*

![Formula 6](https://latex.codecogs.com/svg.latex?I_{N}%20=%20\begin{bmatrix}1%20&%200%20&%20\dots%20&%200\\0%20&%201%20&%20\dots%20&%200\\\vdots%20&%20\vdots%20&%20\ddots%20&%20\vdots\\0%20&%200%20&%20\dots%20&%201\end{bmatrix})  
*Це одинична матриця порядку $N$.*
